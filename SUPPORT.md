# Getting help

- **Questions and problems:** open an issue with the bug report template.
  Include the ECHO version (shown in the installer and *Export diagnostics*),
  your Windows version, steps to reproduce, and what you expected.
- **Feature ideas:** open an issue with the feature request template.
- **Security issues:** report privately as described in [SECURITY.md](SECURITY.md).

Please do not upload music files, personal paths or private station URLs.
ECHO is maintained by volunteers; there is no guaranteed response time.
