# License election for the native decoder

`LICENSE-ELECTION.txt` records the license choices ECHO makes for the
libraries statically linked into `libmpv-2.dll`. It is installed with ECHO as
`notices/native/LICENSE-ELECTION.txt` and published in each release's
`ECHO-<version>-license-election.tar.gz`.

`patches/` holds the notice changes of the LGPL 2.1 section 3 election,
generated by `scripts/elect-gplv3.ts` from the pristine archives listed in
`SOURCES.txt`. To regenerate one, extract its archive and run:

```powershell
bun scripts/elect-gplv3.ts <extracted directory> <output directory> <name>
```

The patches touch comments, documentation and build metadata only; lines
holding string literals in source code are left alone so the compiled
decoder is unchanged. `texts/` holds upstream license texts that the
election statement relies on.

Updating any of these libraries requires regenerating its patch and
reviewing its `*-remaining-references.txt`.
