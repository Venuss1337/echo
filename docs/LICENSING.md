# Licensing and redistribution

## ECHO

ECHO's own code and documentation are licensed under the GNU General Public
License, version 3 or (at your option) any later version. See
[LICENSE](../LICENSE). Contributions are accepted under the same license.

Dependencies keep their own licenses. ECHO's GPL licensing is a deliberate
choice: it is compatible with the GPL-licensed decoder stack ECHO ships, and
it keeps the whole application free software.

## Source and notices package

Each release publishes, beside the installer and for that exact build:

- **`ECHO-<version>-source.tar.gz`**: the complete ECHO source at the
  release commit, including lockfiles, the decoder recipe and every build,
  packaging and installation script.
- **`ECHO-<version>-rust-crates.tar.gz`**: the published crates.io source
  for the complete `Cargo.lock`, including crates needed for offline
  dependency resolution.
- **`ECHO-<version>-js-packages.tar.gz`**: the published packages bundled
  into the renderer, which ships minified.
- **`ECHO-<version>-native-source.tar`**: the decoder's upstream source
  archives, the MSYS2 source archives (sources, recipes and patches) of every
  linked package, FFmpeg's generated configuration, Meson options, the link
  map, build receipts, license texts and per-file checksums.
- **`ECHO-<version>-THIRD_PARTY_NOTICES.txt`** and the machine-readable
  inventory, generated by `scripts/collect-app-notices.ts` from the
  lockfiles; every component must provide its license text or the build
  fails. Texts missing from a published crate are vendored verbatim from the
  crate's upstream commit in `notices/crates`.
- **`SHA256SUMS.txt`** and GitHub build-provenance attestations.

The installation itself carries `LICENSE.txt`, `SOURCE.txt` (where the
source for that build is published and the commit it came from), the
application notices and the decoder's license texts under `notices/`.

The native archive preserves the recipes and inputs for reproducing the
reviewed decoder. Release verification compares the rebuilt and reviewed DLL
hashes.

- **`ECHO-<version>-license-election.tar.gz`**: the license choices for the
  decoder's statically linked libraries, with their notice patches and the
  upstream texts they rely on (see below).

## Decoder license choices

The maintainer decided the distribution terms for 1.0.0; they are recorded in
[`native/windows-x64/license-election/LICENSE-ELECTION.txt`](../native/windows-x64/license-election/LICENSE-ELECTION.txt),
which is also installed as `notices/native/LICENSE-ELECTION.txt`. This is the
project's own decision, not an external legal opinion. In short:

1. **LGPL code, converted to GPLv3.** libplacebo, the LGPL files of mpv and
   FFmpeg, FriBidi, libiconv and the gettext runtime library (with its Gnulib
   modules) are distributed in ECHO's copy under the GNU GPL, version 3 or
   later, as section 3 of the LGPL 2.1 permits. The notice changes are
   generated by `scripts/elect-gplv3.ts` and kept as patches against the
   pristine archives in
   [`license-election/patches`](../native/windows-x64/license-election/patches).
   They change comments, documentation and build metadata only; string
   literals in code are untouched, so the shipped DLL is byte-identical to
   the reviewed build. The release workflow checks that the patches apply to
   the pinned archives.
2. **Graphite2** is used under its MIT grant.
3. **FreeType** is used under the FreeType License, because its alternative,
   GPL-2.0-only, cannot be combined with GPLv3. Its credit appears in the
   README and the installed notices.
4. **Ryu** in libstdc++ is used under the Boost Software License 1.0;
   **fast_float** under its MIT license.
5. **GCC runtime** objects are covered by the GCC Runtime Library Exception;
   MinGW-w64 and winpthreads under their permissive notices.
6. **Unicode tables** generated into HarfBuzz, FriBidi and libunibreak are used
   under the Unicode License V3; generators and tables are part of the
   distributed sources.
7. **Installer and runtime.** The NSIS stub and Tauri's NSIS plugin are
   zlib/libpng and MIT/Apache-2.0 licensed. The WebView2 runtime is not
   shipped; the installer fetches Microsoft's bootstrapper only if needed.
8. **Patents.** MP3 and AAC decoders are included; no patent rights are
   granted beyond those in the licenses themselves.

Every release repeats this review for changed components: updating a
decoder library means regenerating its patch and reviewing its
`*-remaining-references.txt`.

## Dependency policy

- New Rust crates must satisfy `deny.toml`: an allowed license, crates.io
  only, no unknown registries or Git sources. `bun run test:security` checks
  this together with advisories.
- New npm packages must be MIT, ISC, BSD, Apache-2.0 or similarly permissive
  for anything bundled into the renderer.
- Shipped assets (fonts, images, audio fixtures) need a license compatible
  with GPL-3.0 and their license text in the repository. No copyrighted
  music or artwork is committed; test audio is synthesized
  (`tests/fixtures/audio/README.md`).
