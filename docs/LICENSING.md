# Licensing and redistribution

## ECHO

ECHO's own code and documentation are licensed under the GNU General Public
License, version 3 or (at your option) any later version. See
[LICENSE](../LICENSE). Contributions are accepted under the same license.

Dependencies keep their own licenses. ECHO's GPL licensing is a deliberate
choice: it is compatible with the GPL-licensed decoder stack ECHO ships, and
it keeps the whole application free software.

## Source and notices package

Each release publishes, beside the installer and for that exact build:

- **`ECHO-<version>-source.tar.gz`**: the complete ECHO source at the
  release commit, including lockfiles, the decoder recipe and every build,
  packaging and installation script.
- **`ECHO-<version>-rust-crates.tar.gz`**: the published crates.io source
  for the complete `Cargo.lock`, including crates needed for offline
  dependency resolution.
- **`ECHO-<version>-js-packages.tar.gz`**: the published packages bundled
  into the renderer, which ships minified.
- **`ECHO-<version>-native-source.tar`**: the decoder's upstream source
  archives, the MSYS2 source archives (sources, recipes and patches) of every
  linked package, FFmpeg's generated configuration, Meson options, the link
  map, build receipts, license texts and per-file checksums.
- **`ECHO-<version>-THIRD_PARTY_NOTICES.txt`** and the machine-readable
  inventory, generated by `scripts/collect-app-notices.ts` from the
  lockfiles; every component must provide its license text or the build
  fails. Texts missing from a published crate are vendored verbatim from the
  crate's upstream commit in `notices/crates`.
- **`SHA256SUMS.txt`** and GitHub build-provenance attestations.

The installation itself carries `LICENSE.txt`, `SOURCE.txt` (where the
source for that build is published and the commit it came from), the
application notices and the decoder's license texts under `notices/`.

The native archive preserves the recipes and inputs for reproducing the
reviewed decoder. Release verification compares the rebuilt and reviewed DLL
hashes. The redistribution review must separately determine what notices,
installation information and relinking materials the selected grants require.

## Release approval required

Public binaries are distributed only after the maintainer has approved the
following points for the exact release. Source code may be published at any
time; these concern binaries.

1. **Static LGPL components.** libplacebo, FriBidi, libiconv, libintl and the
   LGPL parts of mpv and FFmpeg are statically linked into `libmpv-2.dll`.
   ECHO's proposed route is to distribute the combined DLL under the GPL
   together with its source and build scripts. Confirm the exact per-file
   grants, required notice changes and whether LGPL-2.1 §3 or a static-link
   route such as §6(a) applies to each component. Record the chosen route
   and any additional materials required before approval.
2. **Graphite2.** Its files carry alternative grants (LGPL-2.1-or-later,
   GPL-2.0-or-later or MPL). Confirm that the linked files permit the route
   in point 1 and record which grant is relied upon.
3. **Ryu in libstdc++.** The linked `floating_to_chars.o` contains Ryu code
   offered under Apache-2.0 or Boost-1.0. The source archive includes both
   texts; the grant relied on must be chosen and recorded. fast_float in
   `floating_from_chars.o` carries an MIT notice, preserved in the GCC
   source.
4. **Gnulib members of libintl.** `windows-mutex` and `wgetcwd-lgpl` are
   linked; confirm their per-file license headers against point 1.
5. **Generated Unicode tables.** HarfBuzz (Unicode 18.0.0), FriBidi
   (Unicode 14.0.0) and libunibreak (line-break data 15.0.0) embed tables
   generated from Unicode data. Confirm the Unicode license notice to ship
   and whether the generation inputs must accompany the source, since some
   upstream recipes fetch mutable URLs.
6. **GCC and MinGW runtime.** Confirm that the GCC Runtime Library Exception
   covers each linked GCC object for this build process, and that the
   MinGW-w64 startup and winpthreads notices are complete. Windows system
   DLLs (UCRT, Schannel) are part of the operating system and not shipped.
7. **Codec and market considerations.** The decoder includes MP3 and AAC
   decoders. No patent or market-specific review has been made.
8. **Application and installer source.** Confirm the preferred source for
   modifying the bundled JavaScript dependencies, the NSIS stub and plugin
   sources and notices, and the Microsoft WebView2 bootstrapper terms. Verify
   that the exact build’s source and instructions are sufficient under the
   selected distribution terms.

The open questions above are tracked in the repository's issues once
public; a release records the decision for each point in its notes.

## Dependency policy

- New Rust crates must satisfy `deny.toml`: an allowed license, crates.io
  only, no unknown registries or Git sources. `bun run test:security` checks
  this together with advisories.
- New npm packages must be MIT, ISC, BSD, Apache-2.0 or similarly permissive
  for anything bundled into the renderer.
- Shipped assets (fonts, images, audio fixtures) need a license compatible
  with GPL-3.0 and their license text in the repository. No copyrighted
  music or artwork is committed; test audio is synthesized
  (`tests/fixtures/audio/README.md`).
